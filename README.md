# Interlinear Reader

Веб-приложение для чтения английских текстов с построчным переводом и личным словарём.
Всё работает в браузере: тексты, кэш переводов и словарь лежат в IndexedDB, перевод делает встроенный
переводчик браузера на устройстве. Сервера, ключей и запросов в интернет нет.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 в Chrome 138+ или Edge. Для сборки статики — `npm run build`, результат в `dist/`.

Приложение подходит для любого языка, который умеет переводить браузер: английский, испанский, французский, немецкий, китайский и другие.

## Языки и переводчик

Используется Translator API браузера (Chrome 138+, Edge): бесплатно, без ключа и лимитов, перевод выполняется на устройстве.
В Firefox и Safari этого API нет.

- **Язык текста** выбирается при добавлении текста; если в браузере есть LanguageDetector API, он определяется автоматически по вставленному тексту.
- **Язык перевода** задаётся в Настройках → Языки («Переводить на»), по умолчанию русский.
- **Языковые пакеты.** Для каждой пары «язык текста → язык перевода» браузер один раз скачивает пакет (несколько десятков мегабайт).
  В Настройках → Языки виден статус пакета для каждого добавленного языка и кнопка «Загрузить языковой пакет»; та же кнопка появляется в читалке при первом открытии текста.
  Там же для каждого языка выбирается голос озвучки.
- **Что зависит от языка.** Леммы, части речи, фразовые глаголы и правила для артиклей и `be` работают только для английского (при переводе на русский).
  Для остальных языков слова переводятся как есть; для китайского, японского и тайского слова режет `Intl.Segmenter`.
  Разбиение на предложения учитывает сокращения английского, испанского, французского, немецкого, итальянского, португальского и русского.
- Словарь хранит язык у каждой записи: «son» по-испански и «son» по-английски — разные слова, фильтр по языку появляется, когда языков больше одного.

## Что умеет

- **Чтение.** Текст режется на предложения через `Intl.Segmenter` (плюс склейка ложных разрывов после `Mr.`, `Dr.`, `e.g.`, инициалов и перед строчной буквой). Слева английское предложение, над каждым словом перевод, справа полный перевод. Нумерация строк, плотная вёрстка, на узком экране колонки складываются.
- **Два перевода у слова.** `ctx` — перевод формы слова из текста, `base` — перевод начальной формы `lemma`, плюс часть речи `pos`. Предложение переводится целиком, слова — по отдельности. Леммы и части речи считает локально библиотека `compromise` (`went → go`, `children → child`), она же склеивает фразовые глаголы с частицей (`found out`, `get back`). Артикли показываются как «–», формы `be` — как формы «быть», вспомогательные `do/does/did` и вводное `there` помечаются как непереводимые.
- **Контекстный перевод слов.** Пословный перевод без контекста даёт мусор («Vale» → «ваучер»), поэтому после показа строки каждое слово переводится ещё раз внутри своего предложения: предложение отправляется переводчику с этим словом в квадратных скобках («¿Qué [tal]? — Bien, gracias.»), и из скобок в ответе берётся подсказка `ctx`. Если скобки потерялись, остаётся перевод отдельного слова. Строки показываются сразу с черновыми подсказками, уточнённые подставляются по мере готовности и попадают в кэш.
- **Перевод выделения.** Выделите мышью или долгим нажатием несколько слов внутри предложения: выделение прилипает к целым словам, рядом появляется перевод фразы с озвучкой и кнопкой «В словарь». Так переводятся выражения и фразовые глаголы, которые пословный перевод не ловит.
- **Проверка.** Токены строятся из самого предложения, поэтому их конкатенация всегда восстанавливает оригинал; выравнивание проверяется перед показом.
- **Режимы подсказок.** Видны / по наведению (и по тапу на сенсорном экране) / скрыты. Переключение кнопкой или клавишей **H**. Место под подсказку сохраняется, текст не прыгает.
- **Карточка слова.** Клик по слову: `ctx`, `base`, `lemma`, часть речи, озвучка слова и предложения, сохранение в словарь. Сохранённые слова подсвечиваются в тексте.
- **Словарь.** Поиск, фильтры по тексту и части речи, сортировка, озвучка, удаление, экспорт в JSON. Одно и то же слово из разных текстов не дублируется — новое предложение добавляется в `examples`.
- **Повторение.** Карточки: слово и предложение-источник, затем ответ. Слово считается выученным после трёх верных ответов в разные дни (`cleanHitDays`); несколько ответов за день — один; «не знал» обнуляет серию и возвращает слово через пару карточек.
- **Озвучка.** `speechSynthesis`, голос en-US / en-GB и скорость выбираются в настройках. Перед каждым воспроизведением вызывается `cancel()`, подсветка снимается по `onend`.
- **Кэш.** Предложения, слова и фразы хранятся в IndexedDB и не переводятся повторно. При открытии текста переводится только то, чего нет в кэше.
- **Пачки и повторы.** Предложения переводятся пачками (по умолчанию 10, настраивается), готовые показываются сразу. Сбои повторяются с паузами 1 с, 2 с, 4 с, затем строка помечается непереведённой с кнопкой «Повторить».

## Структура

```
src/lib/languages.js      список языков
src/lib/segment.js        разбиение на предложения с учётом сокращений языка
src/lib/gloss-local.js    токены, леммы, части речи, правила для служебных слов (compromise)
src/lib/align.js          проверка, что токены восстанавливают предложение
src/lib/providers/        адаптер: встроенный переводчик браузера и офлайн-заглушка
src/lib/translate.js      кэш, пачки, повторы с паузами
src/lib/words.js          словарь, дедупликация, логика выученности
src/lib/tts.js            озвучка
src/components/           экраны: Library, NewText, Reader, WordCard, Dictionary, Review, Settings, SelectionPopover
```

Версия с переводом через языковые модели (Gemini, Groq, OpenRouter, Claude, Ollama) осталась в истории репозитория до коммита `2b2561a`,
версия с Google Cloud Translation API — до коммита `113f361`.
