# Interlinear Reader

Веб-приложение для чтения английских текстов с построчным переводом и личным словарём.
Всё работает в браузере: тексты, кэш переводов и словарь лежат в IndexedDB, ключ API — в localStorage.
Сервера нет. По умолчанию перевод делает встроенный переводчик браузера на устройстве; для браузеров без него есть Google Cloud Translation API.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Для сборки статики — `npm run build`, результат в `dist/`.

## Переводчики

### Встроенный переводчик браузера (по умолчанию)

Translator API, есть в Chrome 138+ и Edge. Бесплатно, без ключа и лимитов, перевод выполняется на устройстве.
Языковой пакет en→ru (несколько десятков мегабайт) скачивается один раз: кнопка «Загрузить языковой пакет» в Настройках или прямо в читалке.
В Firefox и Safari этого API нет — там нужен Google Translate.

### Google Translate (для других браузеров)

Используется официальный Cloud Translation API (v2). Бесплатно 500 000 символов в месяц, дальше 20 $ за миллион.
Для активации нужен проект Google Cloud с платёжным аккаунтом, в пределах квоты списаний нет.

1. В https://console.cloud.google.com создайте проект и включите **Cloud Translation API** (APIs & Services → Library).
2. В **APIs & Services → Credentials** нажмите **Create credentials → API key**, скопируйте ключ.
3. Ограничьте ключ: *Application restrictions → Websites* (ваш домен), *API restrictions → Cloud Translation API*.
4. В приложении: **Настройки → Google Translate**, вставьте ключ, нажмите «Проверить подключение».

Текст в 30 предложений расходует около 5 000 символов (предложения целиком плюс уникальные слова и леммы).
Повторное открытие текста берётся из кэша и не расходует ничего; переводы отдельных слов тоже кэшируются.

## Что умеет

- **Чтение.** Текст режется на предложения через `Intl.Segmenter` (плюс склейка ложных разрывов после `Mr.`, `Dr.`, `e.g.`, инициалов и перед строчной буквой). Слева английское предложение, над каждым словом перевод, справа полный перевод. Нумерация строк, плотная вёрстка, на узком экране колонки складываются.
- **Два перевода у слова.** `ctx` — перевод формы слова из текста, `base` — перевод начальной формы `lemma`, плюс часть речи `pos`. Предложение Google переводит целиком, слова — по отдельности, без контекста. Леммы и части речи считает локально библиотека `compromise` (`went → go`, `children → child`), она же склеивает фразовые глаголы с частицей (`found out`, `get back`). Артикли показываются как «–», формы `be` — как формы «быть», вспомогательные `do/does/did` и вводное `there` помечаются как непереводимые.
- **Проверка.** Токены строятся из самого предложения, поэтому их конкатенация всегда восстанавливает оригинал; выравнивание проверяется перед показом.
- **Режимы подсказок.** Видны / по наведению (и по тапу на сенсорном экране) / скрыты. Переключение кнопкой или клавишей **H**. Место под подсказку сохраняется, текст не прыгает.
- **Перевод выделения.** Выделите мышью или долгим нажатием несколько слов внутри предложения: выделение прилипает к целым словам, рядом появляется перевод фразы с озвучкой и кнопкой «В словарь». Так переводятся выражения и фразовые глаголы, которые пословный перевод не ловит.
- **Карточка слова.** Клик по слову: `ctx`, `base`, `lemma`, часть речи, озвучка слова и предложения, сохранение в словарь. Сохранённые слова подсвечиваются в тексте.
- **Словарь.** Поиск, фильтры по тексту и части речи, сортировка, озвучка, удаление, экспорт в JSON. Одно и то же слово из разных текстов не дублируется — новое предложение добавляется в `examples`.
- **Повторение.** Карточки: слово и предложение-источник, затем ответ. Слово считается выученным после трёх верных ответов в разные дни (`cleanHitDays`); несколько ответов за день — один; «не знал» обнуляет серию и возвращает слово через пару карточек.
- **Озвучка.** `speechSynthesis`, голос en-US / en-GB и скорость выбираются в настройках. Перед каждым воспроизведением вызывается `cancel()`, подсветка снимается по `onend`.
- **Кэш.** Ключ — `провайдер:sha256(предложение)`. При открытии текста запрашивается только то, чего нет в кэше.
- **Пачки и повторы.** Предложения переводятся пачками (по умолчанию 10, настраивается), готовые показываются сразу. Сетевые ошибки и 429 повторяются с паузами 1 с, 2 с, 4 с, затем строка помечается непереведённой с кнопкой «Повторить».

## Структура

```
src/lib/segment.js        разбиение на предложения
src/lib/gloss-local.js    токены, леммы, части речи, правила для служебных слов (compromise)
src/lib/align.js          проверка, что токены восстанавливают предложение
src/lib/providers/        адаптер: встроенный переводчик браузера, Google Cloud Translation API, офлайн-заглушка
src/lib/translate.js      кэш, пачки, повторы с паузами
src/lib/words.js          словарь, дедупликация, логика выученности
src/lib/tts.js            озвучка
src/components/           экраны: Library, NewText, Reader, WordCard, Dictionary, Review, Settings
```

Версия с переводом через языковые модели (Gemini, Groq, OpenRouter, Claude, Ollama) осталась в истории репозитория до коммита `2b2561a`.
