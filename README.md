# Interlinear Reader

Веб-приложение для чтения английских текстов с построчным переводом и личным словарём.
Всё работает в браузере: тексты, кэш переводов и словарь лежат в IndexedDB, ключи API — в localStorage.
Сервера нет, наружу уходят только запросы к выбранному переводчику.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Для сборки статики — `npm run build`, результат в `dist/`.

## Что умеет

- **Чтение.** Текст режется на предложения через `Intl.Segmenter` (плюс склейка ложных разрывов после `Mr.`, `Dr.`, `e.g.`, инициалов и перед строчной буквой). Слева английское предложение, над каждым словом контекстный перевод, справа полный перевод. Нумерация строк, плотная вёрстка, на узком экране колонки складываются.
- **Два перевода у слова.** `ctx` — перевод в этом контексте, `base` — словарное значение начальной формы `lemma`, плюс часть речи `pos`. Фразовые глаголы и сокращения идут одним токеном, пунктуация прилипает к слову, артикли показываются как «–», формы `be` — как формы «быть».
- **Проверка ответа модели.** После каждого ответа токены выравниваются по исходному предложению посимвольно; при расхождении запрос по этому предложению повторяется один раз, иначе строка помечается ⚠ с кнопкой перевести заново.
- **Режимы подсказок.** Видны / по наведению (и по тапу на сенсорном экране) / скрыты. Переключение кнопкой или клавишей **H**. Место под подсказку сохраняется, текст не прыгает.
- **Карточка слова.** Клик по слову: `ctx`, `base`, `lemma`, часть речи, озвучка слова и предложения, сохранение в словарь. Сохранённые слова подсвечиваются в тексте.
- **Словарь.** Поиск, фильтры по тексту и части речи, сортировка, озвучка, удаление, экспорт в JSON. Одно и то же слово из разных текстов не дублируется — новое предложение добавляется в `examples`.
- **Повторение.** Карточки: слово и предложение-источник, затем ответ. Слово считается выученным после трёх верных ответов в разные дни (`cleanHitDays`); несколько ответов за день — один; «не знал» обнуляет серию и возвращает слово через пару карточек.
- **Озвучка.** `speechSynthesis`, голос en-US / en-GB и скорость выбираются в настройках. Перед каждым воспроизведением вызывается `cancel()`, подсветка снимается по `onend`.
- **Кэш.** Ключ — `провайдер:sha256(предложение)`. При открытии текста запрашивается только то, чего нет в кэше.
- **Пачки и повторы.** Предложения переводятся пачками (по умолчанию 10, настраивается), готовые показываются сразу. Сетевые ошибки и 429 повторяются с паузами 1 с, 2 с, 4 с, затем строка помечается непереведённой с кнопкой «Повторить».

## Провайдеры

Выбираются в Настройках. Интерфейс один: `provider.glossSentence(text) → { full, tokens }`
(и `glossBatch(texts)` для пачек), см. `src/lib/providers/index.js`.

| Провайдер | Бесплатный уровень (октябрь 2026, уточняйте в консоли провайдера) |
|---|---|
| Google Gemini | Есть у Flash / Flash-Lite. Google не публикует фиксированные цифры; лимиты вашего проекта показаны в AI Studio. Для 2.5 Flash обычно порядка 10 запросов/мин и несколько сотен в день. |
| Groq | `openai/gpt-oss-120b`, `openai/gpt-oss-20b`, `qwen/qwen3.8-27b`: 30 запросов/мин, 1 000/день, 8 000 токенов/мин, 200 000/день. Модели Llama 3.x из каталога убраны. |
| OpenRouter | Модели `:free`: 20 запросов/мин, 50/день; после покупки 10 $ кредитов — 1 000/день. Неудачные запросы считаются. |
| Claude API | Бесплатного уровня нет. Opus 5.5 — 4 $/20 $ за 1M токенов, Sonnet 5.5 — 2 $/10 $, Haiku 5.5 — 0,10 $/0,50 $. |
| OpenAI-совместимый сервер | Ollama, LM Studio или любой URL с `/chat/completions`. Офлайн и бесплатно. Для Ollama нужен `OLLAMA_ORIGINS=*`. |
| Без перевода | Заглушка: текст как есть, переводы пустые. |

Одна пачка из 10 предложений с двумя переводами на слово — это примерно 1,5–2,5 тысячи токенов ответа, поэтому кэш обязателен.

## Проверка промта на реальной модели

```bash
node scripts/check-prompt.mjs --provider groq --key ВАШ_КЛЮЧ --model openai/gpt-oss-120b
node scripts/check-prompt.mjs --provider gemini --key ВАШ_КЛЮЧ --model gemini-2.5-flash
node scripts/check-prompt.mjs --provider custom --url http://localhost:11434/v1 --model llama3.1 --file text.txt
```

Скрипт переводит 21 предложение (или ваш файл) и печатает: сколько предложений восстановились из токенов посимвольно, какие многословные токены выделила модель, какие леммы она дала неправильным глаголам, и пример полного ответа.

## Структура

```
src/lib/segment.js        разбиение на предложения
src/lib/align.js          проверка, что токены восстанавливают предложение
src/lib/providers/        системный промт, адаптеры Gemini / Groq / OpenRouter / Claude / custom / stub
src/lib/translate.js      кэш, пачки, повторы с паузами
src/lib/words.js          словарь, дедупликация, логика выученности
src/lib/tts.js            озвучка
src/components/           экраны: Library, NewText, Reader, WordCard, Dictionary, Review, Settings
scripts/check-prompt.mjs  проверка промта из консоли
```
